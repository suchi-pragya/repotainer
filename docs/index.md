# Repotainer documentation

Repotainer aims to generate reproducible Dev Container configurations from repository files. The current CLI resolves paths and reports Git context; configuration generation is not implemented.

- [Architecture](architecture/overview.md): current design, component responsibilities, and open design questions.
- [Contributing](contributing/index.md): project setup, development environment, and checks.
- [Decisions](decisions/index.md): significant choices, their reasoning, and alternatives.

Keep documentation close to the code it explains. Update an existing page when possible; add pages only when real content needs them. Significant future designs can start as proposed ADRs, clearly separated from implemented behavior.
